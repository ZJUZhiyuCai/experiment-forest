# 实验森林前端打磨 · 交付说明

基线：v0.3.0 `3f1e5c5a`。本轮只动视觉与展示结构；保存 / 上传 / 重试 / 版本冲突 / 提案接受逻辑、所有文案、状态判断、事件与 `ctrl.*` 调用均未改动。

## 看到的问题（按影响排序）

1. **提案审阅层级过深**：紫框 → 灰色系统记录条 → 每处改动一圈描边 → “现在 / 提议”两块实心底，四层容器；“现在”灰块被拉高，空出大片灰。
2. **推断类改动的斜纹底**噪点大，深色下尤其刺眼。
3. **深色“理一理”对比度不足**：#a594f9 配白字约 2.5:1；浅色渐变饱和度偏高。
4. **“接受”不像主要操作**，和“拒绝”权重几乎一样。
5. **页头属性行拥挤**：三颗独立描边日期胶囊，视线没有落点。
6. **表格像电子表格**：每格竖线、灰表头、灰行号列，添加列的空白列也带边线。
7. **底部托盘**一条硬分隔线，和正文割裂。
8. 次要：`.fa-btn` 悬停偏灰像禁用；侧栏选中项没有落点；阴影单层偏硬；搜索框悬停规则是无效值（`color-mix(… 140%)`），从未生效。

## 实际修改

### `work/client/forest.css`

- **令牌**（浅色、`prefers-color-scheme` 深色、宿主显式浅色、宿主显式深色四处同步）：新增 `--fa-ai-solid` / `--fa-ai-ink` / `--fa-ai-line`、`--fa-shadow-float`、`--fa-ease-spring`；`--fa-shadow-sm/md/lg` 改为“发丝描边 + 贴地短影 + 远处柔影”的分层阴影。
- **提案卡**：只保留一层卡片；顶部一道 1.5px 紫→绿极细光带 + 极淡顶光（“模型提议、由你决定”）；待定计数改为中性小胶囊。
- **改动行**：去掉每行描边，改为发丝线分隔；左侧 2px 状态细线沿用页面 AI 块的约定——实线紫 = 待定，**虚线紫 = 推断**（替代斜纹底），绿 = 已接受，灰 = 已拒绝。
- **对照**：“现在”只留发丝框、灰字；“提议”极淡紫底 + 紫色细框，聚焦编辑时浮起为白底 + 紫色光圈；标签前加状态小圆点。中间一枚 CSS 画的箭头：预览区够宽（≥460px，按预览区自身宽度的尺寸容器判断）时左右对照 →，侧栏里上下对照 ↓。
- **模型自述**改为引语样式（斜体 + 灰色引线）；**系统记录**改为发丝描边的可展开行，展开后转为浅灰底，右侧指示箭头随展开旋转。两者一眼可分的原则不变。
- **复选框**（仅改动行与“全选待定”）：圆角方块，选中紫色填充 + 弹出对勾；边框用 `--fa-text-4` 保证可辨；强制配色模式下回退原生控件。
- **接受按钮**：柔紫实底，比“拒绝”多一级权重；禁用态为浅灰底、灰字，不再半透明发虚。
- **“理一理”**：改用 `--fa-ai-solid` 实心紫（浅色 #6e56cf 约 5.4:1，深色 #7357d9 约 5.1:1，均为白字）+ 顶部一线高光；悬停时星芒轻转、阴影加深，按下回弹。面板与“发送”按钮同步；常用要求改为描边胶囊；等待横幅加紫色细框，“知道了 / 不再等待”改为紫色（原为绿色，语义不一致）。
- **页头**：标题上方多留呼吸、字距略收、光标改为森林绿；日期“今天 / 昨天 / 选日期”拼成一个贴合的小分段；“（自动记录，不等于实验日期）”降一级灰（文字保留）；页面状态胶囊改为发丝描边，AI / 警告 / 失败胶囊保持实底。
- **表格**：表头不铺灰、字重 600；横向发丝线、竖线减淡到 55%；行号列透明；添加列那一列不画格线；悬停行轻微高亮；空白单元格斜纹保留（含义不变）但更淡。只读表格同步。
- **托盘与输入框**：去掉硬分隔线与毛玻璃，改为上沿 20px 渐隐（`pointer-events: none`，只覆盖正文底部 28px 留白内的滚动区域）；输入框 18px 圆角浮卡、聚焦森林绿光圈；工具按钮改胶囊悬停。
- **其它**：`.fa-btn` 悬停改为更浅底色 + 阴影抬起，ghost / primary / danger 相应调整；侧栏选中项图标改为森林绿；搜索框悬停修复为发丝描边；图片悬停微抬；灯箱加背景模糊与缩放入场；“已处理的提案 N”改为带折叠箭头的安静灰色开关。
- **窄屏**（≤520px）：提案卡与改动行内边距收紧；移除已被尺寸容器取代的旧 `.fa-op__preview.is-diff` 规则。

### 3. 规则变化

- **未选中边线**：`inset 0 0 0 1.5px var(--fa-check-edge)`。
- **键盘焦点**（`:focus-visible`）双重提示：实色 2px 焦点环、隔 2px 底色缝（选中的紫色实底上也分得清）；未选中时边线同步加粗为 2px 焦点色。不依赖半透明、不依赖动画。
- **禁用态**：悬停变紫的提示加 `:not(:disabled)`，禁用框不再暗示可点；禁用仍是 `opacity: .45` + `not-allowed`，语义不变。焦点规则同样排除禁用，且与悬停优先级相同、位置在后，同时悬停 + 聚焦时以 2px 焦点边线为准。
- 选中态（紫色实底 + 对勾）、选中对勾动画、文案、事件、业务逻辑均未改动。

### 4. 顺带修正的首轮缺陷：强制配色回退从未生效

首轮的 `@media (forced-colors: active)` 回退块位于文件靠前位置，与后面的主规则优先级相同，后者的 `appearance: none` 会覆盖回退，**原生复选框回退实际上不起作用**。本轮给回退块每条选择器加一级真实存在的祖先类（`.fa-op .fa-op__check`、`.fa-prop .fa-prop__foot .fa-check input`），优先级高于主规则，从而恢复 `appearance: auto`、隐藏自绘对勾；焦点环在该模式下改用系统色 `Highlight`。

### 5. 保持不变

- `prefers-reduced-motion`：沿用全局规则（所有过渡 / 动画压到 1ms），本轮未新增任何动画。
- 未修改其他源码；未运行命令；未发布。
