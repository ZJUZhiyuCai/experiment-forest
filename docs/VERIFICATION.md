## 功能和验证边界

- Obsidian 接入要求 Host 与已注册 vault 位于同一设备、同一操作系统用户下。远端 Host 不会直接写浏览器所在电脑的 vault；没有实现自建跨设备同步服务。
- 同步方向为 Harness → Obsidian。个人阅读笔记可引用生成页面；手动改写、移动或删除生成的实验笔记会提示冲突，不能用同步覆盖解决冲突。Bases 视图首次生成后由 Obsidian 管理，保留自定义排序与筛选；格式规范化不算实验笔记冲突。断开连接保留已生成文件。
- `.recovery` 保留同步更新前的历史副本，不自动清理，会逐渐占用空间。它不是独立备份系统；仍应维护 vault 及 Harness 的备份。
- 同一 profile 使用一个 Host 进程。进程内队列与修订检查不等同于多进程数据库事务；同 profile 共享资料，课题不是权限隔离。
- 来源快照固定本次方法；普通 revision 用于并发控制。本版本未实现通用修订历史、电子签名、机构级审计或多人审批。
- 日期、完成状态和实际观察由用户填写。步骤完成不等于实验成功，AI 内容保留来源和人工复核状态。
- 未保存草稿属于当前浏览器页面会话，不是持久备份。附件、仪器采集、库存扣减和单位换算未实现。
