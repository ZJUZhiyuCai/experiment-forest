## 浏览器完整链路

使用独立 HOME、DSH_HOME 和仅含软件样本的 Obsidian 测试资料库，没有修改用户真实资料库。

1. 新建实验页、填写观察、粘贴 TSV，得到可编辑的三列表格；日期为空，创建时间单独显示。
2. 上传 PNG、MP4 和 CSV，显示图片和原始文本，视频成功载入两秒媒体，原件可下载；刷新和 Host 重启后内容与材料仍在。
3. 点击“理一理”向当前 Harness 会话发送，由官方 Agent loop 调用真实 `forest_page_read`、`forest_page_propose`，界面收到待审提案。
4. 修改其中一处建议再接受，拒绝另一处；接受内容带待核对标记，人工确认后显示核对时间。“原样”仍能找到最初文字与原始表格。
5. 在界面连接测试资料库，自动产生 Markdown、表格、链接和真实材料文件。连接后再追加一句话并批量上传三个文件，没有调用导出或手动同步；库里自动更新，6/6 份材料与输入字节一致。接受的修改存在，拒绝的段落未进入阅读正文。
6. 实际 Chrome 检查完整工作台、侧栏和 420 px 窄屏。截图来自运行页面中的软件验收样本。

本机模拟模型仅用于确定性驱动**真实会话、工具与存储链路**，明确显示“软件验收”，没有调用外部模型、不进入发布包。它不证明 DeepSeek 或其他模型的科学理解、图片识别准确率。本轮没有拿生成内容当作实验事实。实际账号、模型质量与网络故障下的服务商行为未验收。

开发 Host 有意重启期间出现预期的断线重试日志；恢复后继续完成上述操作。

## 发布包安装

独立官方运行时使用 CLI 安装 0.3.0 tarball，无源码链接、无依赖 overrides。检查实际 HTTP RPC、新页面混排、材料分块上传、字节与哈希、重启后登记幂等和附件读取，并继续验证已有 SOP 流程、客户端启动清单与资源路由。Host Storage 使用 Zod 4.4.3，插件使用 Zod 4.6.7。此环境不连接任何资料库、不发起模型请求。

## 使用边界

- 无感同步指同机可访问 vault 的 Harness → Obsidian 单向后台更新。远程 Host 不能直接写浏览器电脑；未实现独立跨设备同步或 Obsidian 编辑回写。
- Obsidian 作为阅读资料库。生成页面/附件被外部编辑、移动、删除时保留现状并提示冲突；Bases 自定义设置保留。断开不会删除文件。
- JSON 包含记录、来源和附件引用，不含原件字节；完整恢复须一并备份 Harness 的附件存储及插件登记域。
- 每文件 64 MiB、每页 100 材料/200 块、每 profile 登记 512 MiB。正文扩展最多 2 MiB、数据库 20 MiB。未完成上传不跨 Host 重启保留；完成登记的原件可恢复。
- 模型正文读取最多 40,000 字符范围，文本材料最多 40,000 字符，截断明确标记。每页最多 100 次读取凭据、30 份提案。快照保留首次、最近和被引用版本，不是逐键永久审计。
- PDF、XLSX、视频和仪器专有文件可保留、下载、同步，本版不理解其内部内容。提醒只保留已有“今天”计划入口，没有自动提醒服务。
- 同一 profile 使用一个 Host 进程。未实现多人权限、电子签名、机构级合规审计；POSIX 同步保护不声明等同 Windows 断电保证。
