# 旧版启动器归档

这里保存重构前 Windows 启动脚本、桌面快捷方式生成器和 Electron 托盘入口的原文，文件名以 `.original.txt` 结尾，仅供历史查阅，不是当前安装入口。

这些脚本依赖旧工作目录和已不存在的 `dev:client` 命令；托盘入口还引用仓库未提供的 `assets/icon.png`。因此没有将它们当作可运行工具迁移，也没有补装 Electron 或重新制作旧快捷方式。根目录的同名文件仅显示说明后退出，不安装依赖、不启动服务、不打开浏览器、不创建快捷方式。

新版请按 [安装指南](../部署指南.md) 使用 DeepSeek Harness 插件；日常操作见 [使用说明](../👋给朋友的使用说明.md)。需要读取旧浏览器数据时，请先看 [迁移说明](../docs/MIGRATION.md)，旧前端命令为 `npm run dev:legacy` / `npm run build:legacy`，须在仓库根目录手动执行。
